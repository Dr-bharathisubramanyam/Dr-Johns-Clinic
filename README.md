# Dr John's Integrated Clinic — TCM · AYUSH

A responsive static website for Dr John's Integrated Clinic in Taramani, Chennai.

## Included
- `index.html`, `styles.css`, `script.js`
- `assets/clinic-logo.jpeg` — supplied logo, used without editing
- Doctor portrait assets
- Trilingual TCM and Siddha patient-resource documents (English, Korean and Japanese)
- Four-language website interface: English, Korean, Simplified Chinese and Japanese
- WhatsApp appointment request form, direct phone links, email and Google Maps link

## Run locally
Open `index.html` in a browser. For best results, serve this folder using any static web server.

## Publish with GitHub Pages
1. Create a GitHub repository (public if using GitHub Free Pages).
2. Upload all files and the `assets` folder, preserving the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear in Settings → Pages.
